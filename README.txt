# لمّة PWA v0.2
نسخة ويب قابلة للإضافة للشاشة الرئيسية عند استضافتها على HTTPS.

## أسهل طريقة نشر مقترحة
1. فك ضغط الملف.
2. افتح Netlify Drop من متصفحك: https://app.netlify.com/drop
3. سجّل الدخول، ثم ارفع مجلد `lamma_pwa_mobile` (أو اسحب محتوياته حسب ما تسمح به الواجهة).
4. بعد النشر افتح رابط الموقع على Chrome في Android.
5. من قائمة Chrome اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق» إن ظهرت.

هذه نسخة واجهات فقط، وليست تطبيق APK أصليًا. البيانات تجريبية؛ لا يوجد Moodle أو معالجة PDF فعلية حتى الآن.
